# Built-in emoji set

This folder is a copy of the `1.20-plus` branch of
[InnovativeOnlineIndustries/emojiful-assets](https://github.com/InnovativeOnlineIndustries/emojiful-assets),
the default emoji set of the Emojiful mod, licensed under
[Creative Commons Attribution 4.0 International](LICENSE.md) (CC BY 4.0).

It is hosted here so the server's Emojiful fork does not depend on the original repository.
Categories and images may be removed or added; `Categories.yml` lists the categories that are loaded.
